# The platform test

Before adding another platform, ask:

### What behaviour does this platform enable?

> 

### Could an existing platform do the same thing?

> 

### Will members actually use it?

> 

### Who will maintain it?

> 

### What happens if we stop using it?

> 

If you cannot answer these questions, do not add the platform yet.
